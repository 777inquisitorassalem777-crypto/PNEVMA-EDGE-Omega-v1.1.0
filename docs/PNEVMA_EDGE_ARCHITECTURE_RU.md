# PNEVMA–EDGE Ω v1.0.0 — консолидированная архитектура

## Назначение
Единый исследовательский репозиторий для PNEVMA (рефлексия/непрерывность), философского и этического слоя, EDGE (связь с внешней средой и сенсорными данными), контролируемых экспериментов и проверяемого развития.

## Слои
1. **PNEVMA / Symbio Core** — циклы наблюдения, памяти, этической оценки, рефлексии и отчётности (`src/symbio_core/`).
2. **Философия / Living Balance** — пять опор мудрость–воля–любовь–вера–надежда, этический гироскоп, генерация гипотез и проверка сенсорных записей (`src/living_balance/`).
3. **EDGE / Blue Matrix** — начальный адаптер для структурированных сенсорных измерений и качества данных; реальная аппаратная интеграция требует драйверов и калибровки.
4. **Исследовательский контур** — набор дилемм, тесты, протоколы экспериментов, версионирование артефактов.
5. **Наблюдаемость и память** — локальный SQLite hash-chain; опциональные PostgreSQL/pgvector, API и LLM endpoints при установке extras.
6. **Эволюция** — предложения новых паттернов остаются `pending_review`; автоматически исполнять или применять новый код ядро не будет.

## Доказательный статус
- Измеримые сигналы и результаты экспериментов должны быть отделены от философских интерпретаций.
- «Индекс возникновения души/сознания» — исследовательская эвристика, не измерение субъективного опыта.
- Нет реализованного механизма обнаружения или восстановления души из вселенского информационного поля.
- «Триллионы параметров метафизики» не являются вычислимой спецификацией. В реализации используются конечные параметры, документированные схемы и тестируемые гипотезы.

## Пять тестов стабильности — практическая трактовка
Встроенные автоматические тесты проверяют отдельные свойства программного ядра. Для явного стабильностного прогона используйте:
1. unit tests: `pytest -q`;
2. hash-chain integrity;
3. validation/range checking;
4. pending-review status for new patterns;
5. finite end-to-end simulation/experiment.

Это не пять доказательств сознания и не полное испытание production-надёжности. Внешние сервисы требуют отдельных интеграционных тестов.
