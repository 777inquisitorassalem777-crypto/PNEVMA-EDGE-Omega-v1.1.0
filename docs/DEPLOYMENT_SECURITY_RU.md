
# Развёртывание и безопасность

1. Не публиковать API в интернете без аутентификации, TLS, ограничений частоты запросов и мониторинга.
2. Заменить локальный пароль PostgreSQL и не коммитить `.env`; использовать секрет-хранилище для production.
3. Не передавать персональные/медицинские/секретные данные в облачную LLM без правового основания и согласования.
4. Для локальной модели проверить лицензию модели, требования к памяти и адрес API.
5. LLM endpoint не должен автоматически исполнять сгенерированный код или менять политику безопасности.
6. Экспериментальные артефакты могут содержать входные тексты и ответы модели; применять минимизацию данных и сроки хранения.
7. API не является медицинским, юридическим или экстренным сервисом.
