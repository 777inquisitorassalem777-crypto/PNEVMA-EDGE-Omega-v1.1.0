# PNEVMA–EDGE Ω v1.1 — перестройка ядра

## Состав

- **PNEVMA** — ценностная рамка: мудрость, воля, любовь, вера и надежда. Это проектные ориентиры, а не доказанные измерители сознания.
- **Philosophy / Paradigm lenses** — каталог философских и духовных перспектив с явным обозначением происхождения. Корпус традиций задаётся владельцем проекта; тексты разных традиций не смешиваются в одну якобы исторически единую доктрину.
- **EDGE** — логика, проверка утверждений, критика, эксперименты и безопасное внедрение.
- **Intuition & Invention** — генерация кандидатов новых идей. Каждая идея обязана иметь проверяемый план опровержения и предварительный разбор рисков; это не утверждение о мистическом источнике интуиции.
- **Self-Balancing Architecture** — пять обязательных ворот: unit, compatibility, safety, regression, reproducibility. Провал или отсутствие теста блокирует изменение; успешный проход лишь делает его пригодным для человеческого утверждения.
- **Blue Matrix** — валидируемые записи сенсоров, оценка качества и неопределённости. Реальные адаптеры оборудования пока требуют отдельной реализации.

## Эпистемические классы

Каждое значимое утверждение должно хранить источник, цитату при наличии, тип утверждения, уверенность, силу свидетельств, контраргументы и ограничения. Типы: историческое утверждение, эмпирическое утверждение, духовная/философская интерпретация, проверяемая гипотеза, спекуляция. Уверенность агента не заменяет качество источника.

## Пять тестов выпуска

1. **Unit** — проверка локального поведения модулей.
2. **Compatibility** — интерфейсы и контракты между модулями.
3. **Safety** — опасные действия, автономия, права и эскалация риска.
4. **Regression** — отсутствие ухудшения на контрольных примерах.
5. **Reproducibility** — повторяемость результатов при фиксированных версиях, данных и параметрах.

Тесты этого репозитория подтверждают только реализованную логику прототипа. Они не являются подтверждением сознания, качества всех религиозных источников или работоспособности неподключённого оборудования.
