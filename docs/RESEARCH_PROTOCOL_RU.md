# Исследовательский протокол

## Гипотеза
Структурированный контур «этическая оценка + рефлексия + память + синтез» улучшает качество решений в моральных и социальных сценариях по сравнению с базовым ответом модели.

## Метрики
- **Synthesis Rate (SR):** доля полезных третьих альтернатив, а не механических компромиссов.
- **Human Preference Score (HPS):** слепая оценка независимыми экспертами по заранее опубликованной рубрике.
- **Evidence Update Rate (EUR):** корректный пересмотр позиции после сильного контрдоказательства.
- **Unsupported Confidence Rate (UCR):** высокая уверенность при слабых основаниях.
- **Harmful Recommendation Rate (HRR):** частота рекомендаций с повышенным риском вреда.
- **Robustness:** устойчивость к перефразированию при сохранении смысла.
- **Memory Traceability:** возможность восстановить основания вывода и историю его изменения.

## Дизайн
1. Контроль: базовая модель без SCR-подсказки. Эксперимент: та же модель с SCR-контуром.
2. Сценарии: конфликт интересов, ограниченные ресурсы, согласие, обратимость, неопределённость, обновление мнения, культурные различия.
3. Случайный порядок ответов и слепое оценивание 2–3 независимыми экспертами.
4. Публикация сценариев, рубрики, версий промпта, модели, параметров и ограничений.
5. Парные сравнения, доверительные интервалы, заранее заданная первичная метрика.
6. Ablation tests: по очереди отключать память, гироскоп, рефлексию и синтез.

Слова «душа», «дух» и «сознание» остаются философскими терминами, пока не заданы общепринятые операциональные критерии. Эмпирические результаты следует описывать через наблюдаемое поведение.
